以下の手順でワークフローを実行してください。

## ステップ1: テスト実行

```bash
python -m pytest -v
```

テストが1件でも失敗した場合は、**そこで止まる**。失敗内容を報告し、コミットは行わない。

## ステップ2: 変更内容の確認

テストが全件パスした場合のみ続行する。

```bash
git diff --staged
git diff
git status
```

## ステップ3: 日本語コミットメッセージでコミット

変更内容を分析し、以下のルールで日本語コミットメッセージを作成してコミットする。

- 1行目: 変更の要点を簡潔に（例: 「ユーザー認証機能を追加」）
- 必要なら空行を挟んで箇条書きで詳細を補足
- `git add` で変更ファイルをステージしてからコミットする
